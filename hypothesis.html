가설검정 시뮬레이션

교과서의 통계적 회귀 흐름인 가설 설정 → 데이터 수집·전처리 → 모델 생성·학습 → 가설검정 → 평가 중, 가설검정에서 사용하는 귀무가설·대립가설·유의수준·p값을 직접 바꾸며 판단해 봅니다.

판단 기준

수업에서는 보통 0.05를 기준으로 연습합니다. 유의수준은 데이터를 보기 전에 정하는 판단 기준입니다.

한 줄 암기

p < α → 귀무가설 기각
“관계가 없다고 보기에는 결과가 너무 드물다.”
p ≥ α → 기각하지 못함
“관계가 없다는 생각을 버릴 근거가 충분하지 않다.”

주의

p=0.03은 “귀무가설이 참일 확률이 3%”라는 뜻이 아닙니다.
귀무가설이 맞다고 가정했을 때, 관찰된 결과처럼 극단적인 결과가 나올 가능성을 나타냅니다.
